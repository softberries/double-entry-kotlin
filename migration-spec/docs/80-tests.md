## 3. Gaps {#gaps}

### 3.2 Spec examples not mapped to a rule (0)

### 3.3 Weak spots in the Ruby suite (inferred)
- `balance_calculator_spec.rb` stubs `Line.where`, so it checks query construction only. The SQL semantics are verified by the oracle (`balance_*.json`).
- Deadlock and lock-timeout handling is tested with **stubbed** exception messages (LE, LK [1:12:*]). Real PG behaviour differs (BR-068, X-04).
- No spec for: NULL-scope duplicate balance rows (BR-070), balance rows surviving failed transfers (BR-031), `lock_accounts` return value (BR-066), the `credits`/`debits` inversion (BR-081),
  rounding/overflow (BR-032), or id-vs-time ordering of historic balances (BR-042).
- Performance specs assert nothing (`spec/performance/double_entry_performance_spec.rb`).
- The specs run with `DatabaseCleaner` truncation (no transactional fixtures) because of the outermost-transaction rule (`spec/support/database.rb:22-30`).
